# Apex Circuit Mobile

모바일 가로 화면에서 실행되는 오프라인 1인칭 포뮬러 레이싱 MVP입니다.

## 포함된 기능

- 1인칭 콕핏 시점과 3인칭 추적 시점 전환
- 기기 기울기 조향 및 좌우 버튼 보조 조향
- 터치 가속·브레이크 버튼
- 7대 AI 차량과 단일 경기
- 1·3·5랩 선택
- 충돌, 오프로드 감속, 랩타임, 순위, 최고 랩 기록 저장
- Circuit de Monaco의 코너 순서를 참고한 자체 제작 모바일 트랙
- 맑은 낮·석양·야간·가벼운 비
- 배경음악 없이 Web Audio 엔진음·카운트다운·충돌·랩·완주 효과음과 진동 피드백
- PWA 캐시를 통한 오프라인 실행

## 실행

`index.html`을 정적 웹 서버에서 열면 됩니다. HTTPS 또는 localhost 환경에서는 홈 화면에 추가할 수 있는 PWA로 동작합니다.

모바일에서는 가로 화면으로 전환한 뒤 THROTTLE을 누르고 휴대폰을 좌우로 기울여 조향합니다. CAM 버튼이나 화면 두 번 탭으로 시점을 바꿀 수 있습니다.

피트스톱, 타이어, 연료, 챔피언십, 커리어 모드는 다음 확장 단계용으로 남겨 두었습니다.
